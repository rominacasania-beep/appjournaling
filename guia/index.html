tu primer ratito

Empezá acá

El journaling puede ser escribir, dibujar, pegar recuerdos o simplemente dejar una palabra en una hoja. No hay una forma correcta.

01

Elegí por dónde entrar

Si tenés ganas de crear, mirá una idea con foto. Si no sabés qué escribir, empezá con una pregunta. No hace falta hacer ambas cosas.

02

Mirá y adaptá

Cada idea trae una imagen real de cuaderno, una explicación y pasos para seguir. Copiá lo que te sirva; cambiá todo lo demás.

03

Hacé un ratito tuyo

Cinco minutos y una frase alcanzan. Podés marcar los pasos, usar el reloj o guardar la idea para otro día.

para tu cuaderno

Materiales para cada etapa

Empezá con lo que ya tenés. Lo demás es para jugar, no un requisito.

lo esencial

Si recién empezás

  • ✦Un cuaderno, hojas sueltas o el papel que tengas
  • ✦Una lapicera o lápiz cómodo
  • ✦Un marcador o resaltador si querés sumar color

Con esto ya podés hacer cualquiera de las ideas. No necesitás comprar nada.

para explorar

Si querés jugar un poco más

  • ✦Marcadores de colores para títulos, bordes y flechas
  • ✦Stickers, washi tape y papeles de colores
  • ✦Recortes de revistas, tickets y fotos impresas
  • ✦Pegamento y tijera para armar collage

Elegí uno o dos materiales que te den ganas de usar; no hace falta tenerlos todos.

para profundizar

Si ya tenés tu ritmo

  • ✦Hojas de distintos tamaños o papeles con textura
  • ✦Sellos, acuarelas o lápices de color
  • ✦Sobres para guardar recuerdos, flores secas o notas
  • ✦Una carpeta para volver a mirar tus páginas

Probá nuevas capas y formatos sin convertirlo en una tarea perfecta.
